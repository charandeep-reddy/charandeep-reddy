# Charandeep Reddy

Freelance web developer in Hyderabad, India. I build business websites, landing pages, online stores and web apps in Next.js and WordPress for clients in India, the UK and the US. I work on my own, so you deal with me directly from the first chat to handover. Consultations are free.

**Website:** [psydevx.app](https://psydevx.app) · **About:** [psydevx.app/about](https://psydevx.app/about)

### what I build

- Business websites and landing pages for local businesses
- Online stores for Instagram and WhatsApp sellers
- WordPress sites you can edit yourself
- Next.js web apps and speed fixes for slow sites
